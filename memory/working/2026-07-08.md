### Ghost Content Delivery Pattern (for future reference)
1. Create post via `mcp__ghost-blog__create_post` — use string arrays for tags/authors, NOT objects
2. Set feature_image via PUT with JWT auth (Python) — html field is silently ignored
3. Set content by converting HTML paragraphs → Lexical JSON, send `lexical` field via PUT
