David never opens an email with "Hi [Name]". His greeting is the first name followed by a comma: "Mark," / "Russell," — nothing else. Verified against his real drafts (Russell Cornwall reply draft).

**Why:** VOICE.md's email conventions and writing-rules.md don't state this explicitly, so "Hi [Name]" slips through when drafting. Recovered transcript content is not voice-approved material.

**How to apply:** First name + comma, blank line, then body. When rebuilding or reusing any previously drafted email, run identity/VOICE.md + identity/writing-rules.md as a post-pass; never copy recovered transcript text verbatim into drafts.
