## Error 2: Wrong Time Selection (err-20260626T051200-JAR002)

**Category:** Process Skip  
**Severity:** Major  
**Failure Mode:** Protocol skip — knew the step (validate time selection), skipped it anyway

### What Happened
Available tee times for Saturday July 4:
- **4:45 PM** ← Available, within preferred window (1:00 PM - 5:00 PM) ✓
- 6:15 PM ← Available, OUTSIDE preferred window (ends at 5:00 PM) ✗
- Other times

I selected 6:15 PM instead of 4:45 PM.

### Root Cause
Step 4d-4e JavaScript logic for mapping available times to "Choose" button indices failed:

```javascript
// Current broken logic:
var lines = body.split("\n").map(...).filter(...)
for (var i = 0; i < lines.length; i++) {
  if (lines[i] === "Choose") {
    result.push(lines[i-1]);  // Get previous line as time
  }
}
```

This assumes one line before each "Choose" button contains the time. If the DOM has nested structure, extra whitespace, or different layout, the index mapping becomes unreliable.

### Impact
- Selected time 1 hour 15 minutes outside preferred window
- Violated Step 4e requirement to find times within preferred window first

### Fix
Rewrite Step 4d-4e to use DOM queries instead of text parsing:

```javascript
// Better approach:
var chooseButtons = Array.from(document.querySelectorAll('button'))
  .filter(b => b.innerText.trim() === 'Choose');

var timeButtons = chooseButtons.map(btn => {
  // Find preceding time element via DOM traversal
  let parent = btn.closest('[data-time-slot]') || btn.parentElement;
  let timeEl = parent.querySelector('[data-time]') || 
              Array.from(parent.children).find(el => 
                el.innerText.match(/\d{1,2}:\d{2}\s(AM|PM)/));
  return {
    time: timeEl?.innerText.trim(),
    button: btn
  };
});

// Filter to preferred window first
let preferred = timeButtons.filter(t => {
  let hour = parseInt(t.time);
  return hour >= 13 && hour < 17;  // 1:00 PM - 5:00 PM
});

if (preferred.length > 0) {
  // Sort by closest to preferred_start (13:00)
  preferred.sort((a, b) => 
    Math.abs(parseInt(a.time) - 13) - Math.abs(parseInt(b.time) - 13)
  );
  preferred[0].button.click();
}
```
