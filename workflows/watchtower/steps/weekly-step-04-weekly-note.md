## YOUR TASK

### Part A — Obsidian vault note

1. Derive the ISO week identifier from today's date: `YYYY-Www` (e.g., `2026-W25`).

2. Read the accumulated-context in full to gather:
   - `weekly_themes` (themes, synthesis notes, content angles)
   - Step-02 `draft_paths` (Obsidian paths of drafts created)
   - Step-03 `proposed_count` and `batch_number`
   - `weekly_tweets` (array of tweet objects from step-02b — each has `text` and `intent_url`)

3. Construct the weekly note:

   **Frontmatter:**
   ```yaml
   ---
   source: watchtower
   week: YYYY-Www
   date: YYYY-MM-DD
   tags: [watchtower, weekly-synthesis]
   themes_count: <int>
   content_candidates: <int>
   sources_proposed: <int>
   ---
   ```

   **Body:**
   ```markdown
   # Watchtower — YYYY-Www

   ## Themes This Week
   ### 1. <theme_title>
   <synthesis note>
   **Content angles:** <angle titles>

   ### 2. ...

   ## Content Candidates
   | Post Title | Draft Path | Channels |
   |-----------|-----------|---------|
   | ... | ... | ... |

   ## Source Proposals
   [N] new sources proposed in `proposed-sources.md` Batch [N]. Awaiting David's approval.

   ## Tweets This Week
   For each tweet in `accumulated-context.weekly_tweets`, output one line:
   `N. <tweet.text> — [Post to X](<tweet.intent_url>)`
   Render all 10. If `weekly_tweets` is empty or absent, write: *No tweets generated this week.*

   ---
   *Generated by Watchtower weekly run on [DATE]*
   ```

4. Write the note to Obsidian `Watchtower/Weekly/YYYY-Www.md` via MCP.

5. Update the Watchtower Weekly artifact using the `Artifact` tool's `publish` action:
