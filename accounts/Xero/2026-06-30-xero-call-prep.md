## The Proposal in 60 Seconds

**What Improving is proposing:** A two-phase AI Workshop for ~500 Xero employees in Denver.

**Phase 1 — Pre-Engagement Prep ($40,000, 6 weeks)**
- Workflow discovery with 12 Xero functional leads
- Build a validated Stage 3 workflow catalog (one per functional group)
- Nominate and activate 18–36 Xero "Builders"
- Facilitate a Builder prep meeting (T-5 to T-7 days before event)
- Deliver complete workshop package T-48 hours before event

**Phase 2 — Workshop Facilitation ($75,000, event day)**
- 500 participants, 72 tables, 12 functional groups
- 2-hour hands-on build: Do / Extract / Improve (3 exercises)
- Every participant builds and submits a Stage 3 task agent
- Post-workshop: Builder registry, eval scores, 30-day program proposal

**Total: $115,000. Both phases required. Fixed-fee, all-inclusive.**
